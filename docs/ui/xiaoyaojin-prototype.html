    合肥・逍遙津之戰

    曹操親征漢中張魯，東線空虛。孫權親率十萬大軍北上，圍攻合肥。守將張遼、李典、樂進手下只有七千餘人。曹操臨行前留下一封教書，封上寫著「賊至乃發」。

    賊至乃發
    若孫權至者，張、李將軍出戰；樂將軍守，護軍勿得與戰。

        版面

        • 桌機（寬 1100 以上）：地圖加右側資訊欄，時間軸在地圖下方。
        • 平板（640–1099）：地圖在上；下方左欄是兵團，右欄是兵力與戰報。
        • 手機（640 以下）：地圖佔上半，時間軸精簡；下方分頁切換兵團、戰報、兵力；列傳從底部彈出。

        操作

        • 拖曳平移地圖，滾輪或「＋／－」縮放；「跟隨」讓鏡頭自動追劇情。
        • 點兵團看兵力、士氣、狀態；點頭像或「查看列傳」看人物。
        • 播放到關鍵事件會跳出劇情演出，可在設定中關閉；點一下立即繼續。

        美術與資料

        • 將領頭像是向量暫代圖，列傳裡附「插畫設定」，正式版交給繪師依設定繪製。
        • 兵力數字與部分部署是依史料的遊戲化推估；戰報引文標明出處。
        • 地理為示意，依「合肥城、施水、逍遙津、巢湖」的相對位置繪製。
