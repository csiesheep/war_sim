    我的建議

    底圖：歷史重播預設用「絹本水墨」，另提供「現代戰史圖」讓想看清楚戰術的玩家切換。「沙盤夜戰」留給之後的親自指揮模式，六角格可以直接當下令的格子。

    兵團：依縮放自動切換。看全局時用「軍事符號」，兵團多也不亂；放大或點選時換成「旗牌合一」；劇情高潮（如黃蓋火船）用「帥旗頭像」特寫。

    史觀：正史、演義用同一套地圖與兵團，差別只在事件與部分兵團（例如演義才有華容道關羽）。戰報會標出處。
